# 🏨 Hotel Reservation System

A Java-based Hotel Reservation System developed using Java Swing and Object-Oriented Programming (OOP). The application provides an easy-to-use graphical interface for managing hotel room reservations, room availability, and booking operations.

## 📌 Features

- View Available Rooms
- Search Rooms by Category
- Book Hotel Rooms
- Cancel Reservations
- Room Categories (Standard, Deluxe, Suite)
- Payment Confirmation Simulation
- Booking Management
- File Handling for Booking Records
- User-Friendly Java Swing GUI

## 🛠 Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- ArrayList Collections
- File Handling (File I/O)
- Event Handling

## 🏗 System Modules

### Room Management
- Maintains room details and availability status.
- Supports multiple room categories.

### Reservation Management
- Stores customer booking information.
- Tracks booked rooms.

### Booking System
- Allows room reservation and cancellation.
- Prevents double booking.

### Payment Simulation
- Simulates payment confirmation before booking.

### File Handling
- Saves booking details to a text file.
- Maintains booking records.
